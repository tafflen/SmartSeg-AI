# Documentation

This folder holds the stable contracts that later implementation stages must follow:

- `architecture.md` — component boundaries and technology choices.
- `serial_protocol.md` — laptop-to-Arduino protocol specification.
- `firebase_schema.md` — mirrored cloud data model and sync behavior.
- `nfc_setup.md` — PN532 serial-reader wiring, offline lookup behavior, and security limits.
- `wiring_diagram.md` — consolidated hardware pin map and prototype bill of materials.
- `architecture_diagram.md` — end-to-end disposal-cycle sequence diagram.
- `api_documentation.md` and `database_schema.md` — implemented API and SQLite reference.
- `installation_guide.md`, `testing_guide.md`, and `end_to_end_test_plan.md` — setup and demo rehearsal material.
- `integration_fixes.md` and `future_improvements.md` — integration audit and roadmap.
